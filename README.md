# JANASHYR — демонстрационная версия

[Открыть JANASHYR](https://kulnezarov.github.io/janashyr/)

Для показа откройте `Launch JANASHYR.cmd` двойным щелчком. Нужен Node.js 22 или новее. Лаунчер открывает JANASHYR в браузере. Если этот проект уже запущен, он откроет существующую страницу. Если порт занят другим приложением, лаунчер попробует следующий. Чтобы выключить предпросмотр, нажмите `Ctrl+C` в окне запуска.

То же можно сделать из терминала командой `npm start`, а затем открыть [localhost:3000](http://localhost:3000/). Зависимости устанавливать не требуется. Node.js раздаёт локальные файлы сайта. Аккаунты, роли и демо-история работают в браузере без подключения к серверу данных.

## Сценарий показа

1. На главной смените язык и откройте «Войти». Вход содержит шесть готовых аккаунтов: волонтёр, психолог, учитель, ученик, пенсионер и помощник пожилых. Можно создать свой локальный профиль с вымышленным псевдонимом.
2. В «Қолдау» откройте психологическую поддержку и посмотрите демо-календарь. Под ролью психолога в профиле можно открыть или закрыть свободные окна демонстрационного специалиста. В бесплатном образовании по очереди попробуйте поиск ученика и наставника. В цифровом помощнике создайте учебную заявку с аккаунта пенсионера, затем возьмите её в работу и завершите с аккаунта помощника.
3. В «Донорлық» найдите центр и оформите демонстрационную запись на сдачу крови. В «Қолжетімді орта» проверьте маршруты и доступные действия. На странице «Менің қалам» выберите район Шымкента, посмотрите группы уборки и запишитесь на подходящее время.
4. Откройте профиль и проверьте историю. На главной откройте чат и попробуйте быстрые запросы. Чат работает по готовым сценариям, без подключения реального ИИ. Текущая переписка хранится в этой вкладке до четырёх часов. Маршрут к парку можно открыть во внешнем сервисе с профилем для кресла-коляски; для показа без геолокации есть пример от центра города.

Профили и история привязаны к адресу предпросмотра и браузеру. При смене порта браузер покажет отдельный набор локальных данных. Используйте вымышленные данные. Заявки, записи, роли и отметки о состоянии районов предназначены для показа. Они не отправляются в учебные или медицинские учреждения, благотворительные организации и городские службы. Данные на интерактивных картах загружаются из Интернета. Демо-маршруты по доступной среде не предназначены для фактической навигации.

## Публикация

GitHub Actions проверяет проект и публикует его в GitHub Pages при обновлении ветки main. Для локальной подготовки файлов выполните npm run build на Node.js 24. Для публикации в подкаталоге передайте имя репозитория, например npm run build -- janashyr.

## Проверки

`npm test` запускает модульные проверки. Для браузерного теста запустите предпросмотр, затем выполните `node scripts/smoke-preview.mjs http://localhost:3000`. Тест использует уже доступный Playwright и Chrome или Edge; при нестандартной установке можно указать путь через `JANASHYR_PLAYWRIGHT` и `JANASHYR_CHROME_PATH`. Проверка создаёт отдельную временную сессию браузера и не меняет данные показа.
