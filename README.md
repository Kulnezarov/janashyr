# JANASHYR — университетская демонстрация

[JANASHYR на GitHub Pages](https://kulnezarov.github.io/janashyr/)

Учебная платформа социальной поддержки для Шымкента. На русском и казахском языках можно показать запись на занятие, донорство, участие в городской акции, обращение о проблеме и работу с картой доступности. Профили, записи, талоны, обращения и метки демонстрационные. Они сохраняются в браузере и не отправляются организациям.

## Запуск и сброс

- На Windows откройте `Launch JANASHYR.cmd` или выполните `npm start` и откройте [localhost:3000](http://localhost:3000/). Нужен Node.js 22 или новее. Устанавливать npm-зависимости не требуется.
- В личном кабинете нажмите **«Сбросить демо-данные»** и подтвердите. Сайт удалит ключи с префиксом `janashyr.` из `localStorage` текущего адреса сайта и `sessionStorage` текущей вкладки. Другие ключи сохраняются. После сброса откроется вход со стартовыми профилями шести ролей и двумя дополнительными примерами учителей. Начальный язык — казахский.
- Локальный сервер и GitHub Pages хранят данные отдельно. Если демо открыто в нескольких вкладках, закройте остальные перед сбросом. Чат другой вкладки может иметь свою историю.

## Структура и данные

| Файлы | Назначение |
|---|---|
| `index.html`, `app.js`, `profiles.js`, `ui.js` | Статическая оболочка, навигация, профили, сброс и общие элементы |
| `education-data.js`, `education-lessons.js` | Учитель, ученик, стартовые слоты, записи, уведомления и отзывы |
| `donor-booking-data.js`, `donor-booking.js` | Демо-центры, правила анкеты, расписание и талоны |
| `city-participation.js`, `city-report-data.js` | Стартовые акции, участие, примеры обращений и статусы |
| `route-*.js`, `access.js`, `api-keys.js` | Карта, маршруты, метки, заявки о доступности и настройки API |
| `scripts/build-pages.mjs`, `.github/workflows/pages.yml` | Сборка статики в `dist/` и публикация на GitHub Pages |

Стартовые слоты и акции вычисляются относительно текущей даты по времени Шымкента. Записи, профили и метки хранятся в `localStorage`. Чат живёт до четырёх часов в `sessionStorage`, там же кэш маршрутов. Фото городского обращения используется для предпросмотра в форме.

## Ключ OpenRouteService

Создайте аккаунт HeiGIT, скопируйте полный **Basic Key** в разделе **API Key** и вставьте его в `ORS_API_KEY` в `api-keys.js`. Затем обновите страницу предпросмотра или пересоберите сайт. Ключ виден в клиентской сборке, поэтому используйте только бесплатный учебный ключ. С пустым ключом доступна учебная схема. [Личный кабинет HeiGIT](https://account.heigit.org/)

После нажатия «Найти» или Enter Nominatim получает введённый адрес. OpenRouteService получает координаты начала и конца маршрута и геометрию зон обхода. Параметры `NOMINATIM_URL` и `NOMINATIM_AUTOCOMPLETE` включают подсказки при наборе на отдельном сервере, который разрешает такой режим. Карта использует данные OpenStreetMap. Доступность следует проверять на месте.

## Сценарий показа и проверка

1. Переключите язык. Войдите по очереди как волонтёр, психолог, учитель, ученик, пенсионер и помощник пожилых.
2. В кабинете учителя создайте слот. Учеником выберите его в каталоге и отправьте заявку. Учителем подтвердите её, затем вернитесь к ученику и откройте уведомление. Отзыв доступен после окончания урока.
3. В донорстве заполните учебную анкету, смените язык между шагами, выберите центр и время. Откройте талон с QR и отмените запись.
4. В «Моём городе» запишитесь на акцию и отмените участие. Оформите обращение, откройте его в кабинете и продвиньте статус.
5. С учебным ключом найдите на карте два адреса в Шымкенте, постройте маршрут, добавьте метку и пересчитайте. Без ключа покажите учебную схему и карту препятствий.

Выполните `npm test` и `npm run build -- janashyr` на Node.js 24. Для проверки сборки скопируйте содержимое `dist/` в папку `janashyr/` внутри отдельной папки и раздайте её родительский каталог статическим сервером. Проверьте сайт по адресу, заканчивающемуся на `/janashyr/`.

Для браузерной проверки выполните `node scripts/smoke-preview.mjs http://localhost:3000` или передайте URL статической сборки с префиксом. Скрипт использует уже доступные Playwright и Chrome или Edge. При нестандартной установке укажите `JANASHYR_PLAYWRIGHT` и `JANASHYR_CHROME_PATH`. Тест создаёт отдельную сессию и сохраняет данные показа в исходном состоянии.
